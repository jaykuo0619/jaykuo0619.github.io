# 2026 縣市長選情預測

2026 年 11 月 28 日台灣 22 縣市長選舉的滾動預測網站。綜合 6/1 以來公開民調、AI 結構基準與每日網路聲量調整，附台灣地圖、6/1 起的每日歷史、時間軸與「關注縣市」頁。

**網站：** https://jaykuo0619.github.io/election/

## 方法

1. **AI 結構基準**：依 2022 年選舉結果、政黨基本盤、現任優勢、9 月前民調與選情評論，判斷每縣市 9/1 起點得票率。這是判斷值，不是調查數據。
2. **民調加權平均**：扣除未表態後換算有效票占比；電話 1.0、網路 0.6、AI 模擬 0.35，政黨委託 ×0.7，每 40 天權重衰減為 1/e；歷史每天只用當天已公布的民調（5 月起公布者）。
3. **每日聲量調整**：每位候選人一條 −1～+1 的淨聲量指數（新聞事件衝擊＋平滑底噪），7 日滾動平均後換算成 ±2.5 個百分點以內的調整。**聲量為估計值，未接入社群監測資料。**
4. **勝率**：σ = √(s₀² + 0.12 × 距投票日天數)，勝率 = Φ(差距 ÷ σ)。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 產生好的網頁（GitHub Pages 直接提供） |
| `model/model.py` | 民調、事件、基準與模型計算，輸出 `data.json` |
| `model/template.html` | 網頁範本 |
| `model/shapes.json` | 台灣縣市 SVG 路徑（由 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas) 投影簡化） |
| `model/assemble.py` | 把資料填進範本，輸出 `index.html` |

## 更新

```sh
# 在 model/model.py 的 P（民調）與 EV（事件）加入新資料後：
sh model/build.sh
```

本網站為預測，不是選舉結果。民調數字取自各媒體報導，請以原始報導為準。
