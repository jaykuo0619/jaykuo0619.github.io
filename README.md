# jaykuo0619.github.io

Personal pitch site of **Jay Kuo** — Production Control Integration Planner at TSMC (Hsinchu),
aimed at a Fab Planner role at TSMC Fab 11, Camas, WA.

## What's here

- `index.html` — the entire site: a single self-contained page with no build step,
  no frameworks, and no external dependencies. Hand-written CSS (light/dark via
  `prefers-color-scheme`), a hand-drawn equirectangular SVG map of the North Pacific
  with an animated TPE→PDX great-circle route and a live day/night terminator computed
  from solar declination, and a dual-clock "time bridge" showing how the Hsinchu and
  Camas workdays interlock.
- `Jay_Kuo_Resume_Planning.pdf`, `Jay_Kuo_Resume_Engineering.pdf` — detailed résumés.

## Run locally

Open `index.html` in a browser. That's it.

Designed & coded by Jay Kuo.
