The problem

急的時候，你需要的不是「最近的廁所」，是「最近、而且能借的廁所」。

地圖 App 找得到廁所，但不會告訴你那間要先消費、那間其實已經關門。要不要消費？店員肯不肯借？現在開著嗎？廁略把這些都先幫你查好。廁所＋策略，急的時候要有策略。

Color code

看顏色，就知道能不能借。One colour per access rule.

  • 免費開放
  • 向店員借用（便利商店）
  • 限消費者（餐廳、速食店）
  • 需付費
  • 條件未知
  • ✕最近 3 天有人回報無法使用

Open now

晚上十一點，
那間還開著嗎？

  • 營業中 · 22:00 打烊
  • 即將打烊
  • ☾已打烊 · 明天 08:00 開門

打開「現在開放」篩選，已經關門的地點自動隱藏，不會白跑一趟。

Data

40,000+

全台廁所地點，一張地圖找完。

  • 使用者的即時回報
